# 🔔 Toast Notification

A simple and interactive **Toast Notification** project built using **HTML, CSS, and JavaScript**.

This project demonstrates how to create temporary notification messages that provide users with quick feedback after an action.

## 🌐 Live Demo

👉 **[Visit Toast Notification](https://aryanh12345.github.io/Toast-Notification/)**

## 🚀 Features

- 🔔 Toast notification messages
- ✅ Success notifications
- ❌ Error notifications
- ⚠️ Warning notifications
- ℹ️ Information notifications
- ⏱️ Automatically disappears after a short duration
- ✨ Smooth notification animations
- 🎨 Clean and modern interface
- 📱 Responsive design
- ⚡ Lightweight and fast

## 🛠️ Technologies Used

- **HTML5** – Notification structure
- **CSS3** – Styling, positioning, and animations
- **JavaScript** – Notification creation and interaction
